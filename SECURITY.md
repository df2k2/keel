# Security policy

Keel takes security reports seriously. Report a vulnerability privately through GitHub's
vulnerability reporting form at https://github.com/df2k2/keel/security/advisories/new. Do not
open a public issue for a security problem.

- We acknowledge every report within 72 hours.
- High and critical issues are fixed within 30 days of acknowledgement, usually sooner.
- Disclosure is coordinated with the reporter; we credit reporters who want credit.
- Security fixes are called out in `CHANGELOG.md` and in release notes.

Supported versions: the current major release and the previous major receive security fixes for
at least twelve months after the current major ships.
